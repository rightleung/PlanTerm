# PlanTerm v1.1 Public Release Implementation Plan

## Execution Rules

Implement v1.1 as additive work on the current integrated `miniso-2026` case. Do not rewrite committed case data, planning formulas, reconciliation thresholds or existing endpoint semantics. The current baseline is a clean `d7709e5` working tree; package/config metadata still reports `0.2.0` while documentation/UI describe later integrated work, so version changes require an explicit release-owner decision and a compatibility note.

The first public-data slice is a stateless preview. No case is created, no uploaded/public payload is persisted to disk, and no public values are silently merged into the MINISO case. A release feature flag keeps live providers disabled until terms and licensing are reviewed.

### Phase 3: Public import domain model and provider protocol

**Backend files**

- `src/models/public_import.py` (new): Pydantic `Exchange` (`LSE`, `A_SHARE`, `HKEX`, `US`), A-share `Venue` (`SSE`, `SZSE`, `BSE`), `PeriodSelection`, `PublicImportRequest`, `NormalizedStatement`, `StatementSource`, `PublicImportPreview`, `PublicImportMapping`, `PublicImportErrorDetails` and typed error-code literals.
- `src/services/public_import/__init__.py`, `providers.py`, `normalization.py`, `errors.py`, `cache.py`, `rate_limit.py`, `fixtures.py` (new): protocol and implementation boundaries.
- `src/config.py`: additive settings for `public_import_enabled`, provider enable flags, executor workers, request/operation deadlines, retry count, cache TTL/size, rate limit and optional live-smoke flag. Defaults keep live providers disabled until approved.

**Provider protocol**

```python
class PublicFinancialDataProvider(Protocol):
    provider_id: str
    def supports(self, exchange: Exchange, venue: Venue | None = None) -> bool: ...
    def normalize_symbol(self, exchange: Exchange, ticker: str, venue: Venue | None = None) -> str: ...
    def fetch(self, request: PublicImportRequest, symbol: str) -> ProviderResult: ...
```

Implement adapters in separate modules, for example `yfinance_provider.py` and `akshare_provider.py`. Load optional packages lazily. yfinance handles US, HKEX and LSE defaults; AKShare handles explicitly mapped SSE/SZSE/BSE A-shares. A provider may decline a venue; the router returns `unsupported_exchange` or `dependency_missing` rather than guessing.

**Symbol normalization**

- US: uppercase, trim, reject URL/control characters, convert class-share `BRK.B`/`BF.A` to provider `BRK-B`/`BF-A`.
- HKEX: require 1-5 digits, zero-pad to four digits, append `.HK`; reject an already conflicting suffix.
- LSE: uppercase alpha/digit ticker, append `.L` for yfinance when absent; reject arbitrary suffixes/URLs.
- A-share: require `exchange=A_SHARE`, `venue=SSE|SZSE|BSE` plus six digits; map `SSE` to `.SS`/AKShare code, `SZSE` to `.SZ`, `BSE` to its approved provider code. A bare six-digit ticker or a missing/unsupported venue is `ambiguous_ticker` or `unsupported_exchange` respectively.
- Record both original ticker and normalized symbol in the response and cache key.

### Phase 4: Provider fetch, normalization, and safety controls

**Fetch execution**

- `src/services/public_import/executor.py` uses a bounded `ThreadPoolExecutor` and semaphore because pandas/provider clients block. Wrap calls with `asyncio.wait_for`; operation deadline is 12 seconds, provider call timeout 8 seconds. Thread capacity is released only when the underlying future completes.
- Retry at most two times with exponential backoff and jitter for connection errors, timeouts and provider 5xx. Never retry invalid/ambiguous/unsupported requests, malformed upstream data or a rate-limit response unless a bounded `Retry-After` is provided.
- `cache.py` provides thread-safe LRU positive cache (256 keys, 900s TTL), negative typed cache (60s; rate limit 15s), and single-flight coalescing. Cache keys include exchange, normalized symbol, period selection, provider and profile flag. Cache values contain no request credentials.
- `rate_limit.py` enforces one upstream request per provider per second by default and returns `rate_limited` without hammering the source.

**Normalization**

- `normalization.py` maps provider fields to stable IDs: `revenue`, `gross_profit`, `operating_profit`, `operating_expense`, `cost_of_sales`, `cash`, `total_assets`, `total_liabilities`, `operating_cf`.
- Normalize period end to ISO date, classify `annual`/`quarterly`, include fiscal year/quarter, mark flow versus stock, deduplicate identical dates deterministically and reject cross-statement period mismatch.
- Preserve native currency ISO code and declared scale (`native`, `thousands`, `millions`). Missing/ambiguous currency is an error; no FX conversion is performed. Values must be finite numbers or null; non-numeric text is `malformed_upstream`.
- Every statement carries provider, source URL, retrieval timestamp UTC, as-of date if supplied, filing/report date if supplied, and `normalization_version='public-import-v1'`.

**Error taxonomy and API mapping**

Map domain exceptions to the existing API shape `{error,error_type,details}` and status codes: validation/invalid exchange/venue/ticker/ambiguity 422; unsupported/dependency missing 422; no data 404; malformed/period/currency 422; rate limited 429; provider timeout 504; provider unavailable 502; unexpected 500. Details may include exchange, venue, normalized symbol, provider and retryable boolean, but never credentials, cookies, authorization headers, raw query strings or stack traces.

## Interfaces and Schemas

### Public import request

```python
class PublicImportRequest(BaseModel):
    exchange: Literal['LSE', 'A_SHARE', 'HKEX', 'US']
    venue: Literal['SSE', 'SZSE', 'BSE'] | None = None
    ticker: str = Field(min_length=1, max_length=24)
    periods: Literal['annual', 'quarterly', 'both'] = 'both'
    include_profile: bool = False
```

Reject whitespace-only, URLs, control characters, unapproved suffixes, non-A-share requests that include a venue, and A-share symbols without an explicit venue. `include_profile` is opt-in and defaults false to minimize upstream calls and personal-data exposure.

### Normalized statement

```python
class NormalizedStatement(BaseModel):
    period_end: date
    period_type: Literal['annual', 'quarterly']
    fiscal_year: int
    fiscal_quarter: int | None
    is_flow: bool
    currency: str
    unit: str
    unit_scale: Literal['native', 'thousands', 'millions']
    values: dict[str, float | None]
    source: StatementSource
```

`StatementSource` includes `provider`, `url`, `retrieved_at`, `as_of`, `filing_date` and `normalization_version`. API serialization uses ISO dates and UTC timestamps.

### Preview-to-dashboard boundary

`PublicImportPreview` is not a `DashboardResponse`. The only v1.1 UI flow is preview rendering. A future projection must explicitly declare native currency, reported-only actuals, synthetic planning session state, and a separate case identifier; it must not reuse `miniso-2026`.

## Proposed ITSSX Delegation Topology

This topology is frozen for a later root decision. The leader does not launch workers, recurse into another leader or invoke `codex exec`. Any worker launch must use explicit ITSSX provider/model/effort and must preserve unrelated changes.

Execution order: Worker A and Worker C may run in parallel because their files do not overlap; Worker B starts after Worker A publishes the CSS/selector contract and owns the JSX migration files; Reviewer D runs only after all implementation reports and evidence are available.

### Worker A: Shell and browser regression

- **Objective:** implement Phase 1 shell contract and browser evidence.
- **Ownership:** `web/src/index.css`, `web/e2e/dashboard.spec.mjs`.
- **No-touch:** backend `src/**`, `data/**`, docs, `web/src/App.tsx`, `web/src/features/**`, `web/src/components/**`, i18n modules, `web/src/main.tsx`, API client/types and package/version files.
- **Inputs/constraints:** screenshot, current DOM/CSS, Phase 1 contract; preserve existing data and behavior.
- **Model/effort/rationale:** `gpt-5.6-terra` / `high`; independent frontend layout and Playwright work with enough reasoning for responsive edge cases.
- **Deliverables:** CSS shell/overflow contract, selector/test-id contract for the JSX owner, viewport tests, screenshots/measurements. Required JSX/ARIA wrapper changes are handed to Worker B and are not implemented by this worker.
- **Validation:** lint, typecheck, build, six-view Playwright matrix, dialog/table scroll ownership.
- **Permitted actions:** local frontend edits/tests only; no network, commits, pushes or external systems.

### Worker B: i18n and locale migration

- **Objective:** implement Phase 2 typed catalogs, fallback/formatting and migrate UI copy.

- **Model/effort/rationale:** `gpt-5.6-terra` / `high`; broad but coherent TypeScript migration independent of provider implementation. This worker starts after Worker A publishes the CSS/selector contract but does not overlap its files.
- **Deliverables:** provider/hooks/catalogs, switcher, API label registry, formatting helpers, catalog/fallback tests.
- **Validation:** lint, typecheck, build, unit tests, agreed browser locale cases and CJK overflow/accessibility checks.

- **Deliverables:** Pydantic schemas, provider protocol/adapters, symbol/period/currency normalization, bounded executor/cache/rate limiter, error mapping, deterministic fixtures/tests, observability hooks.

### Reviewer D: Independent QA/release reviewer

- **Objective:** find blockers and reconcile cross-slice contracts before release.
- **Ownership:** read-only review of all changed files and evidence; no implementation ownership.
- **No-touch:** entire repository, git state and external systems; no edits unless root separately authorizes a narrow test artifact.

- **Model/effort/rationale:** `gpt-5.6-sol` / `high`; independent scrutiny is needed for security, provenance, accessibility, compatibility and legal disclosures.

- **Permitted actions:** read-only inspection and local tests; no source edits, commits, pushes or external calls.

Reconcile the shared contracts in this order: public-import schema and error codes, locale/API label types, shell test IDs/wrappers, existing MINISO response/tolerance invariants, and release evidence.
